Project yang pernah saya kerjakan.

Kalkulator Scientific

Aplikasi kalkulator scientific merupakan program yang dibuat untuk membantu pengguna melakukan perhitungan matematika, mulai dari operasi dasar hingga perhitungan ilmiah. Aplikasi ini dilengkapi dengan fitur seperti sinus, cosinus, tangen, pangkat, akar, dan logaritma. Projek ini dibuat menggunakan bahasa pemrograman Java dengan tampilan yang sederhana dan mudah digunakan.

Project ini merupakan latihan saya dalam mempelajari bahasa pemrograman Java, khususnya dalam membuat aplikasi kalkulator scientific. Melalui projek ini, saya belajar menerapkan logika pemrograman, penggunaan operasi matematika, serta membuat fitur perhitungan seperti sinus, cosinus, tangen, pangkat, dan akar.
